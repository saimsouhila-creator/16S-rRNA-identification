# 16S rRNA Identification — BLAST Results

A standalone public web viewer for the 16S rRNA BLAST identification results.

## Files
- `index.html` — interactive viewer
- `16S_rRNA_BLAST_results.csv` — data displayed by the viewer

## Publication
Upload both files directly to the root of a public GitHub repository and enable GitHub Pages from the `main` branch and `/ (root)`.
